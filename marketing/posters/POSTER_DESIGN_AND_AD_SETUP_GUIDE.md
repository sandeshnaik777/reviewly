## 📐 Exact Canvas Dimensions & Formats

To maximize click-through rates (CTR) on Instagram, Facebook, and Google, create each poster in these two primary dimensions:

1. **Instagram & Facebook Feed (Recommended Primary Format):**
   - **Aspect Ratio:** `4:5` (Vertical Portrait)
   - **Resolution:** `1080 x 1350 pixels`
   - *Why:* Takes up **40% more vertical screen real estate** on mobile phones than square images, dramatically boosting attention and engagement!

2. **Instagram Stories / WhatsApp Status / YouTube Shorts:**
   - **Aspect Ratio:** `9:16` (Full Vertical)
   - **Resolution:** `1080 x 1920 pixels`
   - *Rule:* Keep all text and buttons within the safe center zone (`1080 x 1420 px`) so profile headers and reply bars don't cover the copy.

3. **Google Display Network / Square Feeds:**
   - **Aspect Ratio:** `1:1` (Square)
   - **Resolution:** `1080 x 1080 pixels`

## 🚀 Step-by-Step Creation Workflow in Canva / Figma

### STEP 1: Generate the Background / Product Hero Visual
1. Open [Google Imagen 3 (Gemini)](https://gemini.google.com) or [Midjourney](https://midjourney.com).
2. Copy the exact **Ultra-Realistic Image Prompt** for the poster you want to build (e.g. Poster 1 for Retail, Poster 2 for Cafe, Poster 8 for Diwali).
3. If using Midjourney, append `--ar 4:5 --style raw --v 6.1` to get direct 4:5 vertical proportions.
4. Download the generated high-resolution 4K image.

---

### STEP 2: Assemble the Poster in Canva
1. In Canva, click **Create a design** ➔ **Custom size** ➔ `1080` width x `1350` height pixels.
2. Upload the generated AI photo and set it as the background or placed in the upper/center frame.
3. **Add a Top Badge Pill:**
   - Add a rounded rectangle shape (Corner rounding: `20px`).
   - Color: Light Emerald (`#dcfce7`) or Soft Amber (`#fef3c7`).
   - Text: `⚡ 82% SCAN COMPLETION RATE AT CHECKOUT` (Font: Plus Jakarta Sans, Bold, Size: `22px`).
4. **Add the Main Headline:**
   - Font: Plus Jakarta Sans (ExtraBold 800).
   - Size: `52px` to `60px`.
   - Contrast: Crisp White `#ffffff` with a subtle dark drop shadow if placed over photo, or Deep Navy `#0f172a` if placed over a clean card container.
5. **Add the Sub-headline & 3 Feature Bullets:**
   - Size: `26px` to `28px`.
   - Use green checkmarks (`✓`) before each bullet point.
6. **Add the High-Converting Price & CTA Container at the Bottom:**
   - Create a clean white card box at the bottom (`height: ~240px`).
   - Display the price prominently:
     - Large Sale Price: **₹79** (Size: `64px`, Bold, Orange `#ea580c`).
     - Scratched Old Price: **~~₹499~~** (Size: `36px`, Red `#b91c1c`, Strikethrough line).
     - Discount Pill: **`84% OFF`** (Green badge `#dcfce7`, text `#16a34a`).
   - Add the Primary Button:
     - Background: Gradient from `#ea580c` to `#c2410c`.
     - Text: **Get Smart Stand at KindlyRate.com →** (Size: `28px`, Bold White).
   - Bottom note: *Helpline / WhatsApp: +91 81238 24899*.

---

### STEP 3: Export for Meta & Google Ads
* In Canva, click **Share** ➔ **Download**.
* File type: **PNG** (for maximum crispness) or **JPG** with Quality `100%`.
* Ensure file size is under `5 MB` for fast ad delivery.
